# ============================================================================
# DICOM PHI (Protected Health Information) Tags
# Based on DICOM PS3.15 Table E.1-1 — Safe Harbor De-identification Profile
# 
# Format: (gggg,eeee)  TAG_NAME  [Level]
#   gggg = group number (hex), eeee = element number (hex)
#   Lines starting with '#' are comments, blank lines are ignored.
#
# DICOM Information Model Hierarchy:
#   Patient → Study → Series → SOP Instance
#
#   Patient identified by: Patient ID (0010,0020)
#   Study   identified by: Study Instance UID (0020,000D)  ← NEVER change
#   Series  identified by: Series Instance UID (0020,000E) ← NEVER change
#   Instance identified by: SOP Instance UID (0008,0018)   ← NEVER change
#
# ============================================================================
